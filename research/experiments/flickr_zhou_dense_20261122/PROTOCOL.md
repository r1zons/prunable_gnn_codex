# Flickr · плотный GraphSAGE Zhou

Воспроизводим dense-секцию `train_config/fullbatch/flickr_4x.yml` из [GCNP 3b06464](https://github.com/tedzhouhk/GCNP/tree/3b0646450620419dc6e2de457fc8f1afcbf03754), [Zhou et al., PVLDB 2021](https://www.vldb.org/pvldb/vol14/p1597-zhou.pdf). Ветка модели `graphsage_zhou` использует по два независимых нормализованных выхода по 256 на слой. Полные размерности 500 → 512 → 512 → 7. В конце L2-нормализация и линейный классификатор. Dropout 0,3, Adam 0,05, weight decay 0, gradient clipping 5, 15 эпох. Лучший checkpoint выбирается по validation Micro-F1, при равенстве остаётся первый. Test используется после выбора. 524 807 параметров участвуют в вычислении. Авторская реализация регистрирует дополнительно по 7 элементов scale и offset в классификаторе с отключённой нормализацией, что даёт 524 821.

Данные скачаны по файлам из [Flickr-папки GraphSAINT, указанной GCNP](https://drive.google.com/drive/folders/1apP2Qn8r6G0jQXykZHyNT6Lz2pgzcQyL). Проверяются разделение узлов, диапазон меток, размерности, соответствие `adj_train` индуцированному подграфу train и SHA-256 исходных файлов. StandardScaler подгоняется, как у авторов, по узлам с ненулевой строкой `adj_train`. Опубликованная папка содержит `adj_full`, `adj_train`, признаки, метки и роли, а `adj_val` отсутствует. В этом запуске он восстанавливается как индуцированный подграф train+validation с сохранением исходной индексации и пустыми строками/столбцами test. Это явно зафиксированное отличие. Test использует оригинальный `adj_full`.

Сэмплер повторяет логику GCNP через NumPy/SciPy вместо Cython/OpenMP. Выбирается 6000 корней с возвратом из train, совершаются два перехода по равномерно выбранным соседям. Индуцированный подграф строится по всем посещённым узлам. Коррекции по частотам включения узлов и рёбер оцениваются на coverage >50 с добавлением подграфов группами 200, как при четырёх авторских потоках. При обучении сначала умножается на разреженную матрицу с коррекциями. Используется тот же бюджет обновлений на эпоху и взвешенная cross-entropy. Генератор seed 101 и поток случайных чисел отличаются от C `rand()` с OpenMP. Для полной валидации и теста используется заранее нормализованная COO-матрица и порядок `A(XW)`.

Проверка паритета на отдельной P100 исполняет код класса GraphSAINT авторов и его исходные методы слоёв. Загрузчик подставляет параметры CLI и блокирует неиспользуемый Cython loader только для импорта модели. Код вычисления автора не редактируется. В тренировочном сравнении восстанавливается одинаковое состояние CUDA RNG перед каждым forward. При совпадении всех слоёв и logits с `atol=rtol=2e-5` и строгой перезагрузке открывается gate для Flickr.

На Flickr обе реализации получают выбранные одинаковые веса, признаки и граф. Измерения на одной P100 сравнивают 5 прогревов и 20 проходов с синхронизацией до и после. Порядок двух реализаций чередуется. Измеряются отдельно logits и авторский путь с full-graph loss и вероятностями, без F1, загрузки и подготовки матрицы. Сохраняются отсчёты, медиана, выборочное стандартное отклонение и throughput по 89 250 узлам.

Сырые файлы находятся в `${GNN_ARTIFACT_ROOT}/flickr-zhou-20261122/`. На POLUS корень `~/gnn-p100-20261110/flickr-zhou-20261122/`. Они принадлежат отдельной серии от более ранних Flickr V5 на generated split.
