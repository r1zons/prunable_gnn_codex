# CylinderFlow · один линейный обмен вместо блоков 7–8

Проверяем, улучшает ли замена с одним раундом передачи сообщений прогноз по сравнению с независимыми линейными картами при фиксированных блоках 7–8 и выбранном ранее чекпойнте. Эталон A — Dense. Контроль C — оригинальные обученные узловая и рёберная карты из LSF 1623799. Вариант D вычисляет для каждого направленного ребра линейную поправку из конкатенации векторов отправителя, получателя и ребра. Эта поправка одновременно служит сообщением и добавляется к состоянию ребра. Узловая карта предсказывает приращение по вектору узла и сумме входящих сообщений. Все признаки на внешнем интерфейсе имеют размер 128.

Данные калибровки — те же индексы узлов и рёбер на тех же 32 тренировочных кадрах из исходного файла calibration.json, проверенного по SHA256. Порядок подгонки имеет значение: сначала оцениваем рёберную регрессию, затем вычисляем предсказанные сообщения для всех рёбер каждого тренировочного кадра, суммируем их и оцениваем узловую регрессию только в исходных выбранных узлах. Используем прежнее правило относительной ridge-регуляризации. Интерфейс, энкодеры, декодер, остальные 13 исходных блоков и статистики нормализации зафиксированы. У D больше коэффициентов, чем у C. Контраст D−C измеряет совместный эффект графового обновления и его параметризации.

Валидация, начало окон, веса траекторий, метрики, размер прогрева и шесть порядков исполнения заимствованы из [предыдущего пилота](../meshgraphnet_linear_block_pilot_20261120/PROTOCOL.md). Выполняем A/C/D на одном устройстве в одном задании. Для A и C сверяем каждую из 16 полных кривых с архивной. Первичные метрики — MSE в кадре 100 и T100. Дополнительно приводим среднюю MSE по шагам 1–100 и парные разности по каждой из восьми траекторий. Порог +10% к A служит описательным ориентиром. Для C и D с целью проверки механизма изучаем скорость и качество отдельно. Отложенный test в эксперимент не входит.

Код запуска d0ac9a0. На POLUS запускать scripts/run_cylinderflow_linear_exchange.lsf на одной P100 с четырьмя CPU и 8 ГиБ в существующем окружении предыдущего пилота. Рабочий каталог должен содержать src, используемые scripts и configs, source-commit.txt и source.sha256. Подготовленные исходники, журналы, входные хеши, калибровочные карты и сырые измерения относятся к отдельной группе артефактов meshgraphnet-linear-exchange-20261120. Полные файлы первого пилота используются только для чтения.
