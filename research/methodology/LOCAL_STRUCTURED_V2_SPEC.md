# LOCAL-STRUCTURED-V2

## Спецификация экспериментального протокола

**Дата:** 26 октября 2026 г.  
**Статус:** готово к независимому аудиту; не утверждено для реализации.  
**Репозиторий:** r1zons/prunable_gnn_codex  
**Приоритет:** воспроизводимая сравнительная статья, без расширения исследовательского объёма.

---

## 1. Цель исследования

Исследовать влияние различных алгоритмов выбора скрытых каналов на качество и фактическое структурное сжатие графовых нейронных сетей.

Основная задача — классификация вершин на графе.

Сравнение должно обеспечивать:

- одинаковую исходную обученную модель для всех методов;
- одинаковые доступные операции структурного удаления;
- одинаковое определение достигнутого сжатия;
- независимую оценку accuracy, macro-F1 и времени инференса;
- регистрацию вычислительной стоимости поиска.

Не предполагается заранее, что Q-learning превосходит статические методы.

**Основной научный вопрос:** при одинаковых возможностях структурного удаления обеспечивают ли адаптивные стратегии преимущество перед статическими критериями выбора каналов?

## 2. Модели и структурное удаление

Основные архитектуры:

- GCN;
- GraphSAGE;
- три свёрточных слоя;
- две скрытые размерности по 32 канала.

Общая схема:

$$F\longrightarrow h_1\longrightarrow h_2\longrightarrow C.$$

Удалять можно только скрытые каналы.

Размерности входных признаков $F$ и выходных классов $C$ фиксированы.

Для всех методов V2 применяется единая Local Surgery: удаляются выбранные выходные каналы скрытого слоя и соответствующие входные компоненты следующего слоя.

Минимальная ширина скрытого слоя — 4 канала.

Финальная модель должна содержать физически уменьшенные матрицы параметров. Постоянное маскирование весов не считается структурным сжатием.

## 3. Определение сжатия

Используем только фактическое сокращение числа параметров:

$$s(M)=1-\frac{P(M)}{P_0},$$

где $P_0$ — число параметров dense-модели, $P(M)$ — число параметров после удаления каналов.

Учитываются все параметры, включая удалённые bias.

Целевые значения:

$$s^*\in\{0.30,\;0.50\}.$$

Допуск:

$$\varepsilon=0.01.$$

Он соответствует ±1 процентному пункту и хранится в конфигурации как **target_sparsity_tolerance**.

Достигнутое сжатие всегда регистрируется отдельно от целевого.

Dense-модель без прунинга является контрольной точкой $s=0$.

## 4. Статические методы

Используются четыре метода:

| Метод | Идентификатор V2 | Статус |
|---|---|---|
| Random | random_local_v2 | Включить |
| Magnitude | magnitude_local_v2 | Включить |
| SNIP-based | snip_pt_local_v2 | Включить после проверки |
| GraSP-based | grasp_pt_local_v2 | Условное включение |

Идентификаторы — предлагаемые, их нужно окончательно проверить на конфликт с реестром методов.

### 4.1. Общая процедура

1. Загрузить исходную dense-модель.
2. Вычислить importance на фиксированной модели.
3. Сформировать ранжирования каналов каждого скрытого слоя.
4. Перебрать допустимые пары конечных ширин $(h_1,h_2)$.
5. Для каждой пары построить полную маску сохраняемых каналов.
6. Вычислить фактическое число параметров без физического создания модели.
7. Отобрать варианты с целевым сжатием в пределах допуска.
8. Оценить полные маски по критерию метода.
9. Выбрать одну конфигурацию.
10. Выполнить физическую Local Surgery.
11. Измерить итоговые характеристики.

При ширине 32 и минимуме 4 имеется не более $29^2=841$ пар конечных ширин.

Для каждой пары рассматривается одна маска, определённая заранее рассчитанными ранжированиями каналов.

Это приближённый поиск, не гарантирующий глобально оптимальную маску.

**Для Random** шаги importance/ranking/сравнения по score заменяются случайным выбором допустимой конфигурации и каналов; случайный baseline не получает importance-оракул.

### 4.2. Random

Вариант архитектуры случайно выбирается из допустимого множества.

После этого случайно выбираются сохраняемые каналы соответствующих слоёв.

Распределение выбора предлагается равномерным по допустимым парам ширин и равномерным по подмножествам каналов заданной мощности.

Используется зафиксированный seed.

Запрещается выбирать лучший Random-вариант по validation accuracy либо использовать importance для выбора случайной маски.

### 4.3. Magnitude

Для весов:

$$q_i=|w_i|.$$

Предпочтительно удаление параметров с малым суммарным importance.

Индивидуальная оценка скрытого канала учитывает связанные с ним веса предыдущего и следующего слоя.

При оценке полной маски каждый исчезающий параметр учитывается один раз.

### 4.4. SNIP-based post-training pruning

Для весов:

$$q_i=|w_i g_i|,\qquad g_i=\frac{\partial\mathcal L_{\mathrm{train}}}{\partial w_i}.$$

Градиент вычисляется на фиксированной обучающей выборке.

В отличие от оригинального SNIP, оценки рассчитываются после предварительного обучения модели и используются для структурного удаления целых скрытых каналов.

Должны быть зафиксированы способ формирования train batch, режим dropout и правила обработки нулевых градиентов.

### 4.5. GraSP-based post-training pruning

Кандидатный критерий:

$$q_i=-w_i(Hg)_i,$$

где $g=\nabla_W\mathcal L$, $H=\nabla_W^2\mathcal L$.

Для корректного вычисления требуется Hessian-gradient product с фиксированным вектором $g$, а не производная произведения градиента на веса.

Знак оценки сохраняется. Для signed-критерия необходимо проверить направление сортировки по оригинальной статье и соответствующую агрегацию на уровне каналов.

GraSP включается только после математической, численной и структурной проверки. При неудачной проверке метод исключается без замены упрощённой эвристикой.

### 4.6. Оценка полной маски

Для аддитивных оценок используется сумма importance уникальных удаляемых параметров.

Взаимосвязанные веса, удаляемые сразу несколькими каналами, учитываются один раз.

В основном эксперименте accuracy каждой кандидатной архитектуры не вычисляется. Измеряется accuracy только выбранной и физически сжатой модели.

Маскированный forward используется при необходимости для проверки эквивалентности Local Surgery.

Префиксные суммы допустимы как оптимизация расчёта score, но не обязательны для первой реализации. Сначала проверяется прямой алгоритм.

### 4.7. Недостижимое целевое сжатие

Если ни одна пара ширин не соответствует заданному допуску, выбирается ближайшее достижимое значение сжатия, а затем маска по критерию метода.

Отдельно регистрируются абсолютное отклонение от цели и признак нарушения допуска.

## 5. Адаптивные методы

Используются:

- adaptive_greedy_local_v2;
- q_learning_local_v2.

Оба метода используют одинаковые:

- Local Surgery;
- допустимые слои;
- правила выбора удаляемых каналов;
- пространство действий;
- формулу немедленной награды;
- терминальный штраф;
- максимальную длину траектории.

### 5.1. Пространство действий

$$a=(l,k), \qquad k\in\{1,2,4,8\}.$$

Здесь $l$ — индекс скрытого слоя, $k$ — число удаляемых каналов.

Действие допустимо, если после его применения ширина слоя остаётся не меньше 4.

Можно возвращаться к ранее обработанному скрытому слою. Фиксированного направления обхода слоёв нет.

При выборе конкретных удаляемых каналов оба метода используют Magnitude на текущей модели. Это решение отличается от статического Magnitude, который один раз вычисляет ранжирования на dense-модели.

Максимальная длина траектории:

$$T_{\max}=20.$$

### 5.2. Немедленная награда

Сохраняем действующую формулу Q-learning:

$$R_t=0.6(s_t-s_{t-1})-0.4D_t,$$

где

$$D_t=\max(0,A_0-A_t).$$

$A_0$ — validation accuracy исходной модели, $A_t$ — validation accuracy после текущего действия.

Компонента $0.6\Delta s$ использует сокращение параметров как показатель выгоды. Это не измеренное ускорение.

Альтернативную награду на основе разности функции полезности оставляем для будущего исследования.

### 5.3. Терминальный штраф

$$P(s_T)=-\lambda\max(0,|s_T-s^*|-\varepsilon).$$

Значение $\varepsilon=0.01$ утверждено как значение по умолчанию.

Коэффициент $\lambda$ определяется небольшим предварительным пилотом по validation-данным.

Существующие дополнительные терминальные бонусы и штрафы Q-learning должны быть пересмотрены, чтобы не возникал двойной учёт отклонения от цели.

### 5.4. Adaptive Greedy

На каждом шаге алгоритм оценивает все допустимые структурные действия.

Для кандидата вычисляется его немедленная награда.

Если действие завершает поиск, к оценке добавляется терминальный штраф.

Выбирается кандидат с наибольшей оценкой.

Алгоритм завершается при первом выполнении одного из условий:

$$s_t\geq s^*-\varepsilon,$$

$$t\geq T_{\max},$$

либо при отсутствии допустимых действий.

Если действие перескочило верхнюю границу допуска, результат сохраняется как фактически полученный. Превышение регистрируется.

Adaptive Greedy не имеет обучаемого действия STOP.

### 5.5. Tabular Q-learning

Q-learning выбирает действия по обученной Q-таблице.

Сохраняется явное действие **STOP**.

**Достижение целевого сжатия не приводит к автоматической остановке.**

Принудительное завершение допустимо по лимиту шагов или при отсутствии допустимых действий.

Сохраняются отдельные фазы обучения политики и её применения к исходной dense-модели.

Каждый обучающий эпизод начинается с исходного состояния.

Основным результатом является модель, полученная после фактической остановки политики. Лучшее промежуточное состояние не подставляется вместо результата автоматически.

Число эпизодов обучения остаётся параметром пилота. Первоначальный ориентир — действующие 30 эпизодов; необходимость увеличения проверяется по признакам сходимости и вычислительной стоимости.

## 6. Экспериментальная матрица

### 6.1. Минимальный обязательный набор

Минимальная серия включает **Cora, CiteSeer и PubMed**. Это нижняя граница объёма эксперимента, а не закрытый список датасетов.

Если позволяют сроки, доступные вычислительные ресурсы и готовность к воспроизводимому запуску, можно добавить другие датасеты. Такое расширение должно быть заранее задокументировано, сохранять тот же основной протокол и не задерживать минимальную серию.

**Вычислительная среда: локальная машина и кластер POLUS.** Kaggle и Google Colab не входят в план и не рассматриваются как необходимые или резервные средства выполнения.

От ранее обсуждавшегося пилота сохраняются научные параметры эксперимента, но не предположение об использовании Kaggle.

| Измерение | Значение |
|---|---|
| Датасеты (обязательный минимум) | Cora, CiteSeer, PubMed |
| Дополнительные датасеты | При наличии времени и ресурсов; отдельно зафиксировать расширение |
| Модели | GCN, GraphSAGE |
| Архитектура | 3 слоя, hidden 32 |
| Dense training | Не более 500 эпох |
| Early stopping | Validation loss, patience 50 |
| Целевое сжатие | 30%, 50% |
| Методы | 5 обязательных + GraSP условно |
| Fine-tuning после прунинга | Нет |
| Пилотный seed | 101 |
| Следующие seeds | 202, 303 после успешного пилота |
| Среда | Локальная машина и POLUS; без зависимости от Kaggle/Colab |

Для шести методов полная матрица одного seed в рамках минимального набора содержит максимум 72 сочетания датасета, модели, метода и целевого сжатия.

Dense checkpoint обучается один раз для каждой пары датасет–модель–seed и затем используется всеми методами.

Если GraSP исключён, минимальная матрица сокращается до пяти методов.

### 6.2. Сопоставимость локальной машины и POLUS

Использование двух сред не означает, что их результаты можно без проверки объединять. Нужно зафиксировать версии Python/PyTorch/PyG, доступное оборудование, точные checkpoint hashes, splits и seeds.

Метрики качества можно объединять только при подтверждённой сопоставимости вычислительных условий и общих контрольных артефактов.

**Время инференса измеряется и сравнивается отдельно по каждой аппаратной платформе.** Не объединять локальные и POLUS замеры времени в одну статистическую выборку.

Установку зависимостей и запуск обучения/экспериментов выполнять только по отдельному разрешению исследователя.

## 7. Измеряемые показатели

**Качество:** validation/test accuracy и macro-F1.

**Сжатие:** исходное и конечное число параметров, достигнутое сокращение, абсолютное отклонение от цели, скрытые ширины, размер checkpoint.

**Вычислительная стоимость:** время вычисления importance, время поиска конфигурации, число validation evaluations, время структурного удаления и отдельно время инференса.

**Адаптивные методы:** последовательность действий, награды, значения сжатия и accuracy на каждом шаге, терминальный штраф и причина остановки.

**Q-learning:** число эпизодов, статистика обучения, Q-таблица, исследовательские действия и итоговая траектория применения политики.

## 8. Правила научной корректности

Данные test split не используются для настройки гиперпараметров, обучения политики, выбора масок или принятия решений о включении методов.

Результаты сравниваются с учётом фактического сжатия, а не только запрошенного значения.

Нельзя утверждать превосходство Q-learning без статистически обоснованного сравнения.

Вычислительная стоимость Adaptive Greedy может существенно превышать стоимость одного применения статического метода. Её нужно отдельно показывать.

Изменение пространства выбора и изменение алгоритма выбора — разные факторы. Их нельзя смешивать при причинной интерпретации результатов.

Исторические результаты V1 и новая серия V2 не объединяются без явного указания несовместимости протоколов.

## 9. Совместимость с существующим кодом

Исторические методы и их результаты сохраняются.

Новые методы регистрируются отдельно. Допускается переиспользование низкоуровневых функций, если это не меняет поведение legacy-версий.

Необходимо исправить в новой реализации:

- использование Cascade вместо Local Surgery там, где оно присутствует;
- оценку только первого скрытого слоя в старых структурных методах;
- ошибочную реализацию Hessian-gradient product и потерю знака у GraSP;
- автоматическую остановку Q-learning при достижении целевого сжатия;
- несовпадение пространств действий Adaptive и Q-learning;
- несогласованные терминальные награды.

Старый Group Lasso не включается, поскольку его текущая реализация не эквивалентна полноценному обучению с групповой регуляризацией.

## 10. Обязательные тесты перед экспериментами

1. Физическое сокращение параметров для GCN и GraphSAGE.
2. Эквивалентность выходов корректно маскированной dense-модели и результата Local Surgery.
3. Корректное удаление связанных весов и bias.
4. Правильный подсчёт уникальных удалённых параметров и importance полной маски.
5. Корректность недостижимых целевых уровней сжатия.
6. Корректная обработка действий, ограничений ширины, STOP и завершения траектории.
7. Проверка HVP, знака и устойчивости GraSP.
8. Сохранение и повторная загрузка сжатых checkpoints.
9. Воспроизводимость при одинаковом seed.
10. Отсутствие регрессий в исторических V1-методах.

Если оптимизация префиксными суммами реализуется, она дополнительно проверяется сравнением с прямым вычислением score.

## 11. Открытые вопросы

| Вопрос | Способ закрытия |
|---|---|
| Коэффициент терминального штрафа $\lambda$ | Validation-only пилот |
| Число эпизодов Q-learning | Пилот, диагностика сходимости и времени |
| Политика STOP на нулевом шаге | Независимый аудит и явное правило |
| Scoring bias у статических методов | Единое техническое решение и тесты |
| Направление и структурная агрегация GraSP | Проверка по оригинальной статье и контрольным вычислениям |
| Начальный способ выбора Random-маски | Утвердить предложенное распределение до запуска |
| Равенство вычислительных условий | Отчёт по стоимости поиска; оценка ограничений сравнения |
| Достаточность трёх seeds | Проверка разброса результатов после пилота |
| Размещение запусков на локальной машине/POLUS | Протокол совместимости окружений и checkpoint hashes |

Ни один из открытых вопросов не должен разрешаться по test accuracy.

## 12. Отложенные исследования

Вне основной статьи остаются:

- влияние Cascade и Local Surgery при контролируемом пространстве выбора;
- исследование разных пространств выбора конечных архитектур;
- награда через изменение общей полезности модели;
- различные сценарии приоритета точности и сжатия;
- полноценный Group Lasso;
- систематическое расширение на более крупные и разнородные датасеты (не отменяет возможность добавить датасеты к текущей серии, если позволяют сроки);
- расширение пространства действий для больших архитектур;
- дальнейшая проверка GraSP как post-training критерия.

Эти идеи не включаются автоматически в текущую экспериментальную матрицу.

## 13. Независимый аудит

До реализации провести отдельный read-only аудит спецификации, исходных научных работ и соответствующих модулей репозитория.

Аудитор должен установить:

- математическую корректность формул;
- сопоставимость методов;
- отсутствие противоречий между наградами и условиями остановки;
- корректность адаптаций SNIP и GraSP;
- соответствие предложенных изменений текущей архитектуре программы;
- достаточность тестов;
- воспроизводимость и отсутствие утечки test-информации;
- реалистичность вычислительной стоимости на локальной машине и POLUS.

Результат аудита — таблица критических, существенных и несущественных проблем с доказательствами и минимальными исправлениями.

Аудит не даёт разрешения самостоятельно менять код или проводить обучение.

## 14. Условия начала реализации

Реализация V2 разрешается только после:

1. Рассмотрения независимого аудита.
2. Устранения блокирующих противоречий.
3. Утверждения финальной версии спецификации.
4. Фиксации Git commit, соответствующего протоколу.
5. Отдельного разрешения на изменение кода.

Эксперименты запускаются исследователем вручную после проверки готовности.
