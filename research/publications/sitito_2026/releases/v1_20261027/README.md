# Рукопись для СИТИТО

**Содержательно завершённый комплект для научного редактирования, 27 октября 2026 г.** Новые научные эксперименты не запускались. Основной результат: точный контроль достижимости обеспечивает попадание в параметрический диапазон; дополнительное преимущество табличного Q-learning перед constrained Greedy на этих данных не установлено.

## Основные файлы

- `manuscript_sitito.docx` — основной редактируемый Word, авторские и декларативные поля выделены жёлтым.
- `manuscript_sitito.doc` — дополнительный Word 97–2003 для конференционного пути, где указаны DOC/ODT. Редактировать предпочтительно DOCX; математические объекты в старом DOC могут быть преобразованы экспортёром.
- `manuscript_reading.pdf` — проверенная читательская версия из основного DOCX.
- `source/main.tex`, `source/references.bib` — дополнительный LaTeX/BibTeX; компиляция XeLaTeX → BibTeX → XeLaTeX → XeLaTeX. Рисунки лежат в `figures/` на уровень выше.
- `source/manuscript.md`, `source/references.json`, `source/tables.json` — редактируемое содержание, библиография и таблицы.
- `figures/` — два рисунка, каждый в PNG, SVG и PDF; построены исключительно по существующим CSV.

- `SUBMISSION_CHECKLIST.md` — готовые и незакрытые пункты подачи.

- `DELIVERABLE_SHA256.csv` — контрольные суммы файлов комплекта.

## Честная степень готовности

Текст, числа, иллюстрации и основные файлы готовы для научного редактирования. **Автоматически отправлять комплект пока нельзя**: не заполнены авторы, аффилиации и декларации; не получено фактическое согласование авторами/руководителем; не удалось скачать и сравнить официальный DOCX-шаблон. Word оформлен по доступным официальным текстовым правилам на сайте МГУ. Сайт самого журнала с актуальной редакцией норм прямой подачи был недоступен. Эти ограничения не скрыты за обозначением submission-ready.

Пилот ограничен Cora и одним обученным checkpoint на архитектуру. Отдельные seeds относятся к политикам и маскам; POLUS — парное исполнение, не новое независимое обучение. Все сравнительные выводы о качестве относятся к валидационной части, участвующей в поиске. Это законченная статья на имеющемся наборе данных, а не обещание будущего benchmark.

## Воспроизведение только обработки и оформления

`source/analyze_existing.py` читает компактные CSV/JSON и проверяет совпадение с Git. Он не импортирует Torch, не загружает GNN и не запускает обучение, прунинг или benchmark. `source/build_manuscript.py` создаёт файлы из этих таблиц; `source/package_audit.py` проверяет комплект. Для переноса на другую машину необходимо исправить локальный путь репозитория и установить авторские зависимости (python-docx, numpy, matplotlib, latex2mathml, mathml2omml, lxml, pypdf). Использован отдельный временный каталог библиотек; окружения научных экспериментов не менялись.

Исходный репозиторий и PR не изменялись, коммит/push/merge не выполнялись. Ничего не отправлялось в редакцию, конференцию или другим людям.
