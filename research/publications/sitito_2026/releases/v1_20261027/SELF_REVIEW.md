# Самопроверка по трём ролям

Дата: 27.10.2026. Это три последовательных редакторских прохода одного ассистента, **не независимое внешнее рецензирование**.

## Научный рецензент

- Уточнён вклад: собственная реализация точного ограничения допустимости для данного пространства удалений; универсальная новизна DP, RL и прунинга не заявляется.
- Добавлены точные предпосылки гарантии: начальная достижимость, монотонные целочисленные удаления, неизменный минимум, фильтрация каждого шага, запрет off-band STOP. Указано отсутствие гарантии accuracy/latency и приоритет терминальных событий кода.
- Разведены статический Random V2 и Random действий V3. Общее допустимое множество не выдано за одинаковые конечные архитектуры.
- V1 и короткая функциональная матрица V2 исключены из основной сравнительной таблицы. Нарушение допуска историческим Greedy сохранено.
- Основной отрицательный результат Q относительно Greedy сохранён; лучшие случайные маски не подменяют среднее baseline.
- Включены опубликованные первичные работы 2024/2025/2026 годов; они сопоставлены по постановке без заимствования их чисел для baseline.
- Научный риск: объём экспериментальной базы ограничен; достаточность такого пилотного вклада для журнала решает редакция. Дополнительные результаты не превращают его в многосидовый benchmark.

## Статистик

- Единица независимого обучения: один checkpoint на архитектуру. Policy/mask seeds и парный POLUS не названы независимыми trained models.
- SD пересчитаны из CSV с ddof=1, метрики переведены из долей в проценты; SD accuracy интерпретируется в п.п.
- Не вычислялись p-values, доверительные интервалы или статистическая значимость по трём policy seeds. Нулевой SD Greedy не интерпретируется как внешняя устойчивость.
- 20 случайных масок на условие — описательное распределение. Наблюдения между целями не независимы в смысле нового обучения и не образуют вложенные маски.
- Разброс при одинаковых ширинах сохранён; причинная доля влияния ширин/каналов не оценивалась из несбалансированных групп.
- Все claims о качестве validation-only; обозначена адаптивная зависимость от той же валидации. Отсутствие использования test labels не объявлено доказательством отсутствия validation overfitting.
- Timing SD относится к проходам одной сессии. Независимых аппаратных измерений и причинного CPU-speedup нет.
